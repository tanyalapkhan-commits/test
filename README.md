# КабельПро — сайт на WordPress: оборудование и технологии для прокладки кабеля

Русскоязычный сайт поставщика оборудования для прокладки кабеля по образцу sebinternational.com: структура разделов и подача как у SEB, но **без копирования** чужих текстов, логотипов и торговых марок. Все тексты написаны с нуля, бренд по умолчанию «КабельПро» меняется в одном месте.

## Что внутри

| Что | Где |
|---|---|
| Тема WordPress | `wp-content/themes/kabelpro/` |
| Тексты страниц (HTML + SEO-мета) | `wp-content/themes/kabelpro/content/pages/` — папка = страница, вложенность = уровень меню |
| Контакты по странам СНГ (страна → город → офис + склад) | `wp-content/themes/kabelpro/data/contacts.php` |
| План фото (120 слотов, alt-тексты, сюжеты) | `wp-content/themes/kabelpro/data/photo-plan.json` |
| Промпты для GPT: 20 полотен × 6 фото | `docs/photo-prompts.md` |
| Семантическое ядро | `docs/semantic-core.md` |
| Нарезка полотен на фото | `tools/slice_canvases.py` |
| Подсчёт объёма текстов (знаки без пробелов) | `tools/count_chars.py` |

### Возможности темы
- **Мега-меню до 4 уровней** (Раздел → колонка → пункт → подпункт), на мобильных — аккордеон. Строится автоматически из дерева страниц.
- **SEO**: title и description на каждой странице, keywords, canonical, robots, Open Graph и Twitter Card, Schema.org (Organization, WebSite, BreadcrumbList, Product, Service, TechArticle, FAQPage, LocalBusiness для каждого филиала), хлебные крошки, автоматическое оглавление, ЧПУ, `robots.txt` с Clean-param для Яндекса, XML-карта сайта `/wp-sitemap.xml`, подключение Яндекс.Метрики и GA4, подтверждение Вебмастера и Search Console. Если установлен Yoast, Rank Math или AIOSEO, тема не дублирует их мета-теги.
- **Контакты**: Россия (11 городов), Казахстан (5), Беларусь (2), Узбекистан (2), Кыргызстан, Таджикистан, Армения, Азербайджан, Туркменистан. В каждом городе — офис в бизнес-центре и склад в складском комплексе, без номеров офисов и ворот. Страницы стран и городов создаются автоматически, со своими мета-тегами и разметкой LocalBusiness.
- **Фото-слоты**: каждое фото на сайте — имя слота (`winch-petrol-1`). Пока файла нет, показывается аккуратная заглушка с подписью сюжета. Когда файл появляется, он подставляется сам вместе с alt-текстом.
- **Форма заявки** (всплывающее окно и форма в подвале): заявки уходят на e-mail и дублируются в админке, в разделе «Заявки». Защита — nonce и скрытое поле-ловушка для ботов.
- Быстрая загрузка: без jQuery и сторонних шрифтов, ленивая загрузка фото, отключены лишние скрипты WordPress.

## Установка

1. Нужен хостинг с WordPress 6.2+ и PHP 7.4+.
2. Скопируйте папку `wp-content/themes/kabelpro` на хостинг в `wp-content/themes/`.
3. В админке: **Внешний вид → Темы → КабельПро → Активировать**. При первой активации импорт запустится сам: создадутся все страницы, контакты, главная, ЧПУ `/%postname%/` и мега-меню.
4. Повторный импорт после правки текстов: **Внешний вид → Импорт КабельПро → Запустить импорт**. Чтобы защитить страницу, изменённую вручную в админке, от перезаписи, добавьте ей произвольное поле `_kp_lock` со значением `1`.
5. **Внешний вид → Настроить → КабельПро: настройки сайта** — бренд, телефон, e-mail, соцсети, коды Метрики и GA4, коды подтверждения Вебмастера и Search Console.
6. **Настройки → Чтение** — снимите галочку «Попросить поисковые системы не индексировать сайт».
7. Добавьте сайт в Яндекс.Вебмастер и Google Search Console, укажите карту сайта `https://ваш-домен/wp-sitemap.xml`.

## Фото: 120 штук за один заход

1. Откройте `docs/photo-prompts.md`: там 20 готовых промптов, по одному на полотно 3×2.
2. Сгенерируйте каждое полотно в ChatGPT (или другом генераторе) в максимальном разрешении и при необходимости увеличьте до 8K.
3. Сохраните полотна как `canvases/canvas-01.png` … `canvases/canvas-20.png`.
4. Запустите:
   ```bash
   pip install pillow
   python3 tools/slice_canvases.py
   ```
   Получится 120 файлов WebP в `wp-content/themes/kabelpro/assets/img/photos/`, каждый уже назван по своему слоту.
5. Загрузите эту папку на хостинг — фото появятся на страницах автоматически.

Можно прислать полотна мне: я нарежу их и закоммичу.

## Перед запуском обязательно проверьте

- **Адреса филиалов** в `data/contacts.php` подобраны как ориентир, для примера. Замените их на фактические офисы и склады компании и проверьте названия бизнес-центров и складских комплексов.
- **Телефоны** — в шаблоне стоят заглушки вида `+7 (495) 000-00-00`. Замените их на реальные номера.
- **Технические характеристики** в текстах даны как типовые диапазоны для класса оборудования. Если продаёте конкретные модели, сверьте цифры с паспортами производителя.
- **Политика конфиденциальности** — шаблон. Заполните реквизиты оператора персональных данных (152-ФЗ).

## Объём текстов

Проверка: `python3 tools/count_chars.py` показывает число знаков без пробелов по каждой странице и отмечает страницы короче 20 000 знаков.

## Локальная проверка

Тема проверялась на WordPress 6.5 с SQLite: импорт страниц, мега-меню, контакты, `robots.txt`, карта сайта, разметка Schema.org, вёрстка на десктопе и мобильных.
