# Семантическое ядро: оборудование и технологии для прокладки кабеля

Ядро собрано по тематике «оборудование для прокладки кабеля» и распределено по страницам сайта: один кластер — одна страница, чтобы страницы не конкурировали между собой в выдаче.

**Как собиралось.** Из этой среды нет доступа к Яндекс.Вордстату и платным SEO-сервисам, поэтому частоты не замерялись. Кластеры построены по структуре спроса в нише: тип оборудования × привод × тяговое усилие × задача (класс напряжения, ВОЛС, трубы, ГНБ) × коммерческие хвосты («купить», «цена», «аренда», город). Перед запуском рекомендуем:

1. Прогнать каждый кластер через Вордстат (регион «Россия», плюс Казахстан и Беларусь) и снять точные частоты `"!кабельная !лебедка"`.
2. Сделать кластеризацию по топу Яндекса (Key Collector, Rush Analytics, Topvisor): если для двух запросов в топ-10 совпадает менее 3–4 URL, их лучше разнести по разным страницам.
3. Добавить в ядро марки и модели конкурентов, если планируете продавать их оборудование.

Обозначения: **Т** — транзакционный (купить/цена/аренда), **И** — информационный, **Г** — геозависимый.
